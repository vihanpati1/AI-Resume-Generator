# AI Resume Maker

An AI-powered resume builder that generates professional,
ATS-friendly resume content from user-provided information.

## Features

- AI-generated resume content
- ATS-friendly formatting
- Professional resume preview
- PDF export
- FastAPI backend
- Next.js frontend
- OpenRouter LLM integration

## Tech Stack

Frontend:
- Next.js
- React
- TypeScript
- Tailwind CSS

Backend:
- Python
- FastAPI

AI:
- OpenRouter
- LLM API

## Architecture

User
 ↓
Next.js Frontend
 ↓

 ↓
